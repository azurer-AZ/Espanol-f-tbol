6️⃣ 语法要点 · 结构 + 用法 + 注意
语法点 结构 / 公式 用法说明 对话中的例句 注意事项
无人称 se se + 动词第三人称单数 泛指“人们 / 大家”，不指出主语 A veces se apoya a varias selecciones nacionales. 宾语是复数也不影响，动词仍用单数
después de que + 虚拟式 después de que + subjuntivo 表示“在……之后”，标准语法要求用虚拟式，即使事实已发生 Después de que la selección española ganara... 主句过去时，从句用虚拟式过去未完成；口语中也可用陈述式 ganó
parecer 与主语一致 parecer + 名词 看起来像…… Las fotos parecen un mar de gente. 主语 fotos 是复数，所以用 parecen
trasnochar 不加 se trasnochar 熬夜，不及物动词 Trasnochan para ver el partido. 不是代词式动词，不加 se
hasta los topes 固定短语 满到极点 / 挤爆 Las calles están hasta los topes. 很口语
abarrotado 性数一致 estar + abarrotado/a 挤满的 Las calles están abarrotadas. 修饰 calles 用阴性复数
tripofobia 名词 密集恐惧症 Dan tripofobia. 西语拼写为 tripofobia
procede que + 虚拟式 procede que + subjuntivo ……是合适的 / 应当的 Procede que haya muchas parejas. 主语是后面的 que 从句，动词用单数
no ganó de forma limpia no ganar de forma limpia 赢得不光彩 No ganó de forma limpia. 也可说 poco limpia / deshonrosa
mayoría + 复数动词 la mayoría de + 复数名词 + 动词复数 大多数…… La mayoría de los fans son chicos. 口语中常用复数动词
